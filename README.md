# VisionQuest

VisionQuest is an iOS application that provides mobility assistance to the visually impaired. Auditory direction instructions in conjunction with object detection and depth sensing hazard alerts are used to achieve this.

**Demo:** https://drive.google.com/file/d/1HsEAwznk2U77db46Or6uPlFThlinZ-4I/view?usp=drive_link

## Requirements
- iPhone 13 Pro or greater with at least iOS 26.0
- Working camera
- MacBook with Xcode
- Google Cloud API key with Directions/Places/Maps

## Setup and Installation
 
**1. Clone the Repository**
 
```bash
git clone https://github.com/thisguyblink/visionQuest
```
 
**2. Add Your API Key**
 
In the root project folder, create a `.xcconfig` file named `secret` and add your Google API Key in the following format:
 
```
GOOGLE_API_KEY = YOUR_KEY_HERE
```
 
**3. Enable Developer Mode on Your iPhone**
 
Go to **Settings** > **Privacy & Security**, scroll down to **Developer Mode** and make sure it is on. This will restart your device.
 
## Running the App
 
**4. Open the Project in Xcode**
 
**5. Connect Your iPhone via cable**
 
**6. Select Your Device**
 
In Xcode, select your iPhone as the target from the device dropdown at the top of the window.
 
**7. Run the App**
 
Click the **Play** button in the top toolbar to build and run the app on your iPhone.
 
**8. Stop the App**
 
Click the  **Stop** button in the top toolbar to stop the app while it's running on your iPhone.
